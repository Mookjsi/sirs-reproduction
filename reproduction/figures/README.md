# Figure-generation implementation

`source_adapter.R` and `pipeline_figures.R` define the Phase 4 source-faithful workflow.
No scientific figures have been generated by Codex. User-generated outputs should go
under an explicit fresh --out directory, separate from this implementation directory.

The runner stages the original scripts and data, supplies only the Phase 2 capitalization
helper, loads completed full Phase 3 posteriors, and executes unchanged original plotting
expressions. Prepared input and posterior hashes bind each figure to a campaign.
Main panels, supplemental mapping and source discrepancies are documented in
[../figure_dependency_map.md](../figure_dependency_map.md).

`pipeline_figures.R` provides a metadata/file-only dependency check. Main/supplement figure
commands source scientific code only when invoked manually by the user. The original map
script gets ggplot2 preloaded to satisfy its theme call order; no plot data are changed.
Original tables, panel objects, visible regression output and actual smoothing values are
exported in addition to the original PDF/PNG products. Fonts/version effects remain possible.

[../phase4_execution_plan.md](../phase4_execution_plan.md) contains exact commands;
[../figure_comparison_template.md](../figure_comparison_template.md) defines verification.
